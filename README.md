# Atelier — студия концепта интерьера

Мы делаем **Atelier**: веб-приложение, которое по фото комнаты собирает mood-render нового интерьера.

Это не CAD, не 3D-модель и не строительная документация. Результат — концепт «как может выглядеть», чтобы выбрать стиль, а не чтобы строить по чертежу.

## Для кого

Для человека, у которого есть фото комнаты и идея («хочу индастриал», «убери классику», «оставь короб за унитазом»), но нет бюджета на полный дизайн-проект.

Без аккаунта, без оплаты в базовом сценарии.

## Что умеем

1. Загрузить фото комнаты.
2. Разметить, что сохранить (ракурс, стены, окна, отмеченные объекты).
3. Включить или выключить стили: сканди, минимализм, индастриал и другие.
4. Обсудить детали в чате с Gemini.
5. Получить концепт-рендеры — по два варианта за раз.

## Чем мы не являемся

- не архитектор и не автор рабочей документации;
- не выдаём размеры «в миллиметрах как факт»;
- не строим BIM, планировку БТИ и мебель с артикулами.

На каждом рендере есть пометка: это mood-render, не чертёж.

## Как это устроено коротко

Фото анализирует Gemini Vision. Стиль и правки собираются в английский промпт. Картинку рисует генератор по этому промпту, стараясь сохранить геометрию исходной комнаты. Сессия живёт в браузере (IndexedDB), сервер ключи наружу не отдаёт.

## Запуск локально

```bash
npm install
cp .env.example .env.local
# вписать ключи из .env.example
npm run dev
```

Студия: http://localhost:3000/studio
